1 为什么需要 DH

串联机械臂的 FK 就是把每个关节的相对变换连乘：⁰Tₙ = ⁰T₁ · ¹T₂ · … · ⁿ⁻¹Tₙ。 一个一般的刚体变换有 6 个自由度，但相邻两个关节轴之间只要按约定摆放坐标系，就能用 4 个参数描述，其中 1 个是关节变量（转动关节是 θ，移动关节是 d），另外 3 个是由结构决定的常数。

一句话DH = 一套「如何给每个连杆放坐标系」的约定 + 每个关节 4 个参数 (θ, d, a, α)。参数怎么定义取决于约定，所以拿到 DH 表必须先确认是标准 DH 还是改进 DH。

2 标准 DH（Denavit–Hartenberg，Siciliano / UR 手册常用）

关节 i 连接连杆 i−1 与连杆 i。约定：坐标系 {i} 固连在连杆 i 上，zᵢ₋₁ 沿关节 i 的轴线（所以 {i−1} 的 z 轴是第 i 个关节轴，这是标准 DH 最容易记混的一点）。

坐标系规则

  1. zᵢ₋₁ 沿关节 i 的轴线（转动关节取转轴方向，移动关节取移动方向）。
  2. xᵢ 沿 zᵢ₋₁ 与 zᵢ 的公垂线，方向从 zᵢ₋₁ 指向 zᵢ。两轴相交时 xᵢ = zᵢ₋₁ × zᵢ（正负任选，保持一致）；两轴平行时公垂线不唯一，任选一条，通常选使参数为 0 的那条。
  3. yᵢ 由右手定则补全。
  4. 原点 Oᵢ 在 xᵢ 与 zᵢ 的交点（若 zᵢ 与 xᵢ 不相交，则取使后续参数为 0 的位置）。

四个参数

参数定义（从 {i−1} 到 {i}）关节 i 是转动时性质
θᵢ绕 zᵢ₋₁，从 xᵢ₋₁ 转到 xᵢ 的角度变量（零位偏置记为 θᵢ⁰）关节角
dᵢ沿 zᵢ₋₁，从 xᵢ₋₁ 与 zᵢ₋₁ 的交点到 xᵢ 与 zᵢ₋₁ 交点的距离常数（移动关节时是变量）连杆偏置
aᵢ沿 xᵢ，从 Oᵢ 与 zᵢ₋₁ 的交点到 Oᵢ 的距离（公垂线长度）常数连杆长度
αᵢ绕 xᵢ，从 zᵢ₋₁ 转到 zᵢ 的角度常数连杆扭角

变换矩阵

依次做 4 个基本变换：先绕 z 转 θ，再沿 z 移 d，再沿（新的）x 移 a，最后绕（新的）x 转 α：

ⁱ⁻¹Tᵢ = Rz(θᵢ) · Tz(dᵢ) · Tx(aᵢ) · Rx(αᵢ)

        ⎡ cosθ   −sinθ·cosα    sinθ·sinα    a·cosθ ⎤
      = ⎢ sinθ    cosθ·cosα   −cosθ·sinα    a·sinθ ⎥
        ⎢  0         sinα          cosα         d    ⎥
        ⎣  0          0             0           1    ⎦      （θ=θᵢ, d=dᵢ, a=aᵢ, α=αᵢ）
记忆法左上 3×3 = Rz(θ)·Rx(α)；右列 = (a·cosθ, a·sinθ, d)。θ 只出现在「绕 z」里，α 只出现在「绕 x」里，其余都是常数。

3 给一台机械臂建 DH 表的步骤

  1. 画出机械臂零位（所有关节角=0 的姿态）的线框图，标出每个关节轴 z₀…zₙ₋₁（注意：第 i 个关节轴 = zᵢ₋₁）。
  2. 基座系 {0}：z₀ 沿关节 1 轴，x₀ 任选，通常与世界系对齐。
  3. 逐个关节找公垂线，放 x₁ … xₙ₋₁，原点放在 x 与 z 交点。
  4. 末端系 {n}：zₙ 取接近方向（approach），xₙ 垂直于 zₙ₋₁ 并与之相交，补全 yₙ。
  5. 对每个 i，按上表读出 θᵢ、dᵢ、aᵢ、αᵢ，填表。零位时 θᵢ 可能不为 0（因为 x 轴是按几何放的），此时 θᵢ = qᵢ + θᵢ⁰。
  6. 代入矩阵连乘，用一个能手算的位形（零位、全 90°）核对，再与 URDF / Pinocchio 对比。
平行轴的特殊性相邻两轴平行时公垂线有无穷多条，d 与 a 可以互相「串」。DH 对此是病态的：不同人建出的表不同，但 FK 结果一致。这也是 PoE 不存在此问题的原因（见第 9 节）。

4 改进 DH（Craig 约定，机器人学导论 / 部分国产臂手册）

差别在于坐标系 {i} 固连在关节 i 的轴线上：zᵢ 沿关节 i 轴（不是 zᵢ₋₁），所以下标与关节一一对应，更直观。

参数定义
αᵢ₋₁绕 xᵢ₋₁，从 zᵢ₋₁ 转到 zᵢ
aᵢ₋₁沿 xᵢ₋₁，从 zᵢ₋₁ 到 zᵢ 的距离
θᵢ绕 zᵢ，从 xᵢ₋₁ 转到 xᵢ
dᵢ沿 zᵢ，从 xᵢ₋₁ 到 xᵢ 的距离

变换顺序也变了：先 x 方向的两个，再 z 方向的两个。

ⁱ⁻¹Tᵢ = Rx(αᵢ₋₁) · Tx(aᵢ₋₁) · Rz(θᵢ) · Tz(dᵢ)

        ⎡   cosθ          −sinθ          0        a      ⎤
      = ⎢ sinθ·cosα      cosθ·cosα     −sinα    −sinα·d  ⎥
        ⎢ sinθ·sinα      cosθ·sinα      cosα     cosα·d  ⎥
        ⎣     0              0            0        1     ⎦      （θ=θᵢ, d=dᵢ, a=aᵢ₋₁, α=αᵢ₋₁）

5 标准 DH 与改进 DH 对比

标准 DH改进 DH（Craig）
关节 i 的轴zᵢ₋₁zᵢ
表中第 i 行参数θᵢ dᵢ aᵢ αᵢ（同一行的 a、α 描述连杆 i）αᵢ₋₁ aᵢ₋₁ θᵢ dᵢ（a、α 来自上一连杆）
基本变换顺序Rz → Tz → Tx → RxRx → Tx → Rz → Tz
末端坐标系需额外约定，常多一个工具变换末端系自然落在最后关节上，再接工具变换
典型来源Siciliano、Spong、UR 官方 DH 表Craig、部分国产臂 / ABB 手册
树形 / 分支结构较麻烦更方便（人形双臂常用）
别混用把改进 DH 的表按标准 DH 公式代入，结果会错。判断方法：看手册表头顺序，或用一个已知位形（零位）核对末端位置。
